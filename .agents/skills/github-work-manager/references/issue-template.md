# Executable issue template

```markdown
## Objective
One measurable behavior.

## Parent
<feature/epic URL or None>

## Repository
<owner/repo>

## Context
Minimal architecture and contract links.

## Prerequisites
Actual blocking issue URLs and required merged revisions; None only when verified.

## In scope
- ...

## Out of scope
- ...

## Acceptance criteria
- [ ] AC-1: Observable binary condition.

## Verification
- `<exact command>` — expected result.

## Risks
Security, durability, concurrency, compatibility; or None known.

## Definition of Done
All mandatory gates in the shared definition-of-done reference plus this issue's criteria.

## Evidence
Not yet collected. Fill during execution/verification; never fabricate during planning.
```

Title: verb + specific component + intended outcome. Avoid vague scope such as “complete related work”.
